Publish to the live website

Save all product changes straight to GitHub — your Netlify site auto-deploys within a minute. First time only: enter your admin password and tick "remember".

How publishing works:

  1. Edit your products on the left. Changes are auto-saved on this device as a draft.
  2. Click Publish products. It saves products.json to your GitHub repo.
  3. Netlify detects the change and auto-deploys. Your live site updates in about a minute.
  4. Download products.json is a backup / manual fallback.
